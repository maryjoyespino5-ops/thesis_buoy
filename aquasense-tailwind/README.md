# neleus1 · AI Decision Support Dashboard

A production-ready React application with Tailwind CSS for coastal intelligence monitoring.

## Stack
- React 18 + Vite
- Tailwind CSS v3.4+
- React Router v6
- Recharts for charts
- Lucide React for icons
- Framer Motion for animations
- React Hot Toast for notifications
- shadcn/ui patterns

## Features
- Multi-role dashboard (Admin, LGU, BFAR, Sanctuary, Researcher, Fisherman)
- AI Decision Support with risk assessment and predictions
- Live buoy monitoring with real-time data
- Interactive map with buoy markers
- Fish activity intelligence
- Marine sanctuary monitoring
- Alerts and maintenance tracking
- Dark/light theme toggle
- Responsive design

## Getting Started
```bash
npm install
npm run dev
```

## Build for Production
```bash
npm run build
```
